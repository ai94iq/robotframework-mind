Ask the repo. Get a line.

Exact lookups over Robot Framework test repos: one file:line per hit, so people and agents stop reading whole suites.

Download the app

tests/cases.robot | ticket PROJ-2120

  1. $ python -m robot_mind --root . ticket PROJ-2120
  2. test Change Zone NEW Lists Zones
  3. tests/cases.robot:6
  4. [bug:PROJ-2120 role:role_team_lead op:GET /api/zones/list]

tests/cases.robot | callers "Open Cases Page"

  1. test Change Zone NEW Lists Zones tests/cases.robot:9
  2. test Cases Page Opens For QC tests/cases.robot:13
One file:line per hit. No suite dump.

Agents stop burning tokens on searching.

Command line

CommandReturns
ticket KEYtests that cover it
kw NAMEwhere it is defined
callers NAMEevery call site
tag TAGtests with the tag
find TEXTendpoint, variable, value

Install and run

pip install robotframework-mind[gui]
python -m robot_mind_app

Windows, Mac and Linux builds: releases (unsigned, no budget for signing). On macOS: xattr -d com.apple.quarantine on the app, or build from source.

What you need, and where it runs.

You need

  • Python 3.10 or newer
  • robotframework on PATH
  • A Robot Framework test repo

Works with

  • Any .robot or .resource file
  • JSON files under docs/
  • Windows, Linux and macOS
